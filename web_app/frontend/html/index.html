Web Bluetooth (BLE) • Nạp Wi-Fi vào ESP32-S3

Quét Gateway qua Bluetooth (BLE)

Trình duyệt sẽ tìm kiếm trạm Gateway ESP32-S3 (GATE_S3_CONFIG) qua chuẩn Web Bluetooth GATT.

Cấp nguồn Type-C cho ESP32-S3, LED chuyển xanh dương (BLE Config)
Service UUID: 0x00FF • SSID: 0xFF01 • PASS: 0xFF02
Bật Bluetooth trên máy tính / điện thoại (Google Chrome hoặc Edge)
Chrome đang khóa Web Bluetooth (Tài khoản trường học/tổ chức)

Tài khoản Google đang đăng nhập có chính sách quản lý chặn mở cờ Chrome & Web Bluetooth. Bạn không cần cấp quyền mà hãy chọn Wi-Fi trực tiếp ngay dưới đây:

ĐÃ KẾT NỐI BLE: GATE_S3_CONFIG

Dịch vụ Wi-Fi GATT (0x00FF) đã sẵn sàng nhận dữ liệu.
